Why use External JavaScript files
16
External JavaScript files are the most common way to include JavaScript code for 
a number of practical reasons:

Search engines can crawl and index your web site faster if there is less code 
within your HTML page.


ultimately easier to manage.

can separate the JavaScript files into different folder structures on your web 
server, similar to images, which is an easier way to manage your code. 
Clean, organized code is always key to easily managing your website.

## Page 34

Use const, let, or var ?
34

let, behave in terms of scope as you would expect a java or C++ 
variable. It is recommended to use it whenever possible.

var has scope in functions meaning the variables are valid within the 
function and not outside the function.

Use const if you need to declare a constant (value will be initialized
once and do not change afterwards). Its scope is similar to let to the
nearest enclosing block.

Using const, let, or var outside a function creates a global variable

Var allows redeclaration while Let doesn’t allow redeclaration but 
allows nested block shadowing

considered equal.

then === produces true and !== produces false.


same value, but if they are of different types, they attempt converting the 
values types.

What are web applications?

## Page 129

Web server VS Application server

A web server‘s fundamental job is to accept and fulfill requests from 
clients.


It is enough if the client requests are for static content from a website (HTML pages, files, 
images, video, and so on).
A web server’s clients are often Web browsers

An application server’s fundamental job is to provide its clients with 
access to what is commonly called business logic, which generates 
dynamic content;


it’s transforms data to provide the specialized functionality offered by a business, service, 
or application.
An application server’s clients are often applications themselves and can include web 
servers and other application servers.
